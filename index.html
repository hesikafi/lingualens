Online Demo mode
Demo mode. No Firebase config yet — AI answers are local demos so you can try the whole app. To enable real hybrid AI (on-device Gemini Nano + cloud Gemini Flash), paste your Firebase web config into src/firebase-config.ts. See the README for the 5-minute setup.

Write in English

Type or paste a sentence or paragraph. Grammar correction, rewrites, vocabulary and translation run on-device (Gemini Nano) when available — private, instant, and working even offline — with automatic cloud fallback.
